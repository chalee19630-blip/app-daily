# ProjectPilot AI

A personal and team workspace for managing projects, tasks, and daily plans.

## Features

- Dashboard
- Task management
- Project management
- Calendar and daily planning
- Supabase authentication

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase Auth
- PostgreSQL

## Getting Started

Install dependencies:

npm install

Create a `.env.local` file with your Supabase configuration.

Start the development server:

npm run dev

Open http://localhost:3000 in your browser.
